# Mangala Ustası — web sayfaları

GitHub Pages: https://ibrahimbilgic.github.io/mangala-ustasi/

- `index.html`: uygulamanın tanıtım, destek ve gizlilik bağlantısı (Türkçe)
- `gizlilik.html`: gizlilik politikası (Türkçe ve İngilizce)
- `fonts/`: Outfit ve Instrument Sans (SIL Open Font License)

Bu dosyalar uygulama deposunda `npm run site -- <dizin>` ile üretilir (`tools/site/`). Burada elle düzenleme yapma.
